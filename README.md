# Publisher Exit

Service operations software for preserving Microsoft Publisher libraries, rebuilding active templates, and handing off usable archives to churches and small schools.

Status: planning and repository setup. No application implementation or deployment yet.

## Branches

- `production`: default branch and reviewed release baseline.
- `staging`: ongoing application development.
- Promote staging through a pull request with base `production` and head `staging`. Keep it draft until ready; the owner decides when to merge.
- Branch names alone do not deploy anything.

See [the build plan](build-plan.md) and [development instructions](AGENTS.md).
